# 잿빛 회랑 · 제1장

Godot 기반 전투 프로토타입입니다. SACRATA 지향 군중 전투의 가독성과 디아블로식 장비 드롭·성장을 결합한 5–8분 제1장을 개발하고 있습니다. 현재 제품 후보는30이며, 최종 품질 승인은 아직 진행 중입니다.

## 실행

Godot 4.5.1에서 `project.godot`를 엽니다. 제1장 씬은 `chapter1/ChapterOne.tscn`입니다. 루트 기본 씬 `Baseline.tscn`은 기존 실험을 보존하기 위해 유지합니다. 제1장 씬을 열어 현재 씬 실행으로 확인합니다.

WASD/좌클릭 이동, Space 회피, Q 회복약, I 장비, Esc 정지입니다. 자세한 현재 상태와 남은 검증은 `HANDOFF.md`를 참고하세요.

## 버전 관리 범위

게임 소스·런타임 에셋·라이선스·테스트 소스·구현/패키징 스크립트·소스 고정 매니페스트를 관리합니다. `.godot`, 빌드 EXE, 녹화·캡처·대량 원시 로그·사용자 저장 사본은 제외합니다. 제외 파일은 디스크에서 삭제하지 않습니다. 기존 후보와 성공·실패 증거는 기존 위치에 보존합니다.

이 저장소의 첫 커밋은 현재 작업 상태부터 시작합니다. 과거 후보14~30을 과거 Git 커밋이 있었던 것처럼 재구성하지 않습니다. 기존 후보별 고정 소스·EXE·검사 기록은 별도 보존 자료입니다. 역사적 빌드/연구 스크립트에는 로컬 절대 경로와 외부 보존 디렉터리 의존이 있으므로, 새 컴퓨터에서 그대로 재현되는 배포 스크립트라고 보지 않습니다.

런타임 에셋의 출처와 조건은 `chapter1/art` 및 `assets`의 LICENSE/ATTRIBUTION 문서를 따릅니다. 저장소 자체에 별도 오픈소스 라이선스를 임의로 부여하지 않았습니다. GitHub 공개 범위와 저장소 위치는 사용자와 정한 뒤 연결합니다.

## 작업 원칙

현재 후보·사용자 저장·성공/실패 자료를 보존하고 새 검사는 고유 출력 경로를 사용합니다. 기술 검사 통과를 전체 품질 완성으로 간주하지 않습니다. 추가 툴 개발은 사용자 지시에 따라 보류하고 제1장 품질 개선을 우선합니다.
