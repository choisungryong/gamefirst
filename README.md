# 잿빛 회랑 · 제1장

Godot 기반 3D 군중 전투 게임입니다. 장비 드롭과 성장을 결합한 약 5–8분의 제1장을 개발하고 있습니다.

검증된 직접 실행 기준선은 **후보40**입니다. HUD·성장·장비 UI에 보관함 필터와 정렬, 세 구역 진행 안내, 결과 화면과 냉기 표현을 통합했습니다. 실제 Windows 실행본의 Forward+ 통합 확인26개를 통과했습니다. 후보37·38 실행본과 저장은 보존하고 별도40 저장 공간에 현재38 진행을 한 번 복사했습니다. 이후38·40의 진행은 독립입니다. 최종 성능·전체 수동 완주·음향 청취는 별도이며, 효과음 작업은 후순위입니다.

## 현재 개발 상태 — 2026-11-12

- UI38와 전체 요소 제작실은 c30e8a8로 공개했습니다. 냉기39 소스는 실제 코어 동일성·정지·빙결과 화면 비교를 거쳐 fd6683d로 공개했습니다.
- UI40 보관함 필터·정렬, 세 구역 진행 안내와 결과 화면은 분리 fixture의14캡처·47개 확인을 통과했고, 최초 승리 표시 뒤 포커스도 별도6개 확인을 통과했습니다. 냉기39+UI40 **통합40 제품은 실제 PCK 통합26개 확인을 통과**했습니다. 명시 런타임172개·스테이지174개·PCK311항목 감사를 통과했고, 이전 후보와 프로필 바이트 보존도 확인했습니다.
- 초상41은 원화를 생성하고 관리 툴에 계획 자산으로 등록한 단계입니다. 실제3D 모델이나 제품 UI 적용 완료를 뜻하지 않습니다. 초상을 사용하는 독립 UI41 타이틀 메뉴도 준비 중입니다.

다음 순서는 초상41·메뉴 분리 검증 → 최종 선택 후보의 성능·전체 플레이 관문입니다. 후보40은 바탕 화면의 제1장 바로가기에서 실행할 수 있습니다. 효과음은 후순위로 유지합니다. 각 분리 검사를 수동 완주나 최종 미술 승인으로 확대하지 않습니다.

## 개발 실행

1. 이 저장소를 복제합니다.
   ```sh
   git clone https://github.com/choisungryong/gamefirst.git
   ```
2. 검증에 사용한 Godot **4.5.1**에서 `project.godot`를 엽니다.
3. `chapter1/ChapterOne.tscn`을 열고 **현재 씬 실행(F6)**을 선택합니다.

루트 기본 씬 `Baseline.tscn`은 기존 실험 보존을 위해 유지합니다. 에디터 실행은 저장 비활성 미리보기입니다. 전용 저장 경로를 사용하는 제품 실행본과 구분합니다.

조작: WASD/좌클릭 이동, Space 회피, Q 회복약, I 장비, Esc 정지, E 선택 의식입니다. 기술은 자동 시전됩니다.

## GitHub에 포함하지 않는 자료

`.godot`, 실행본, 패키징 스테이지, 녹화·캡처·대량 원시 로그, 사용자 저장 파일 및 그 사본은 업로드하지 않습니다. 필요한 게임 에셋과 라이선스·출처 문서는 포함합니다. 제외한 로컬 자료를 삭제하거나 과거 증거를 재구성하지 않습니다.

현재 로컬 Git 이력을 그대로 보존합니다. Git 도입 전 후보의 이력을 새 커밋으로 꾸미지 않습니다. 기존 후보별 소스·실행본·검사 원시는 별도 보존 자료입니다.

역사적 빌드·연구 스크립트에는 `C:/Project` 등의 로컬 경로와 외부 보존 디렉터리 의존이 있습니다. 새 컴퓨터에서 그대로 재현되는 배포 도구는 아닙니다. 현재 실행본 제작에는 기존 보존 환경의 패키징 절차를 사용했습니다.

## 라이선스와 상태

런타임 에셋의 출처·조건은 `chapter1/art`와 `assets`의 LICENSE/ATTRIBUTION 문서를 따릅니다. 저장소 자체에 별도 오픈소스 라이선스를 임의로 부여하지 않았습니다.

기능 검사 통과를 최종 미술·음향·재미 완성으로 확대하지 않습니다. 사용자 저장과 기존 후보를 보존하고, 검사는 고유 출력 경로에 기록합니다.
