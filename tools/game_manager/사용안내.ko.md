# 잿빛 회랑 제작실

`open-manager.ps1` 또는 바탕 화면의 **잿빛 회랑 제작실** 바로가기로 엽니다. 주소는 http://127.0.0.1:8781/ 입니다. Python 3.10 이상이 필요하며 외부 서비스에 에셋을 업로드하지 않습니다.

- 분류나 검색에서 캐릭터·몬스터·장비·스킬·맵·UI·효과를 찾습니다.
- 실제 속성, 소스와 연결 근거를 확인합니다. 등록 항목 수에는 구현 파일과 에셋도 포함됩니다.
- 그림과 로컬 3D 모델을 미리 봅니다. 모델은 직접 불러온 뒤 애니메이션을 선택하고 재생합니다.
- **목표와 작업**에서 개선 계획을 보고 상태·우선순위·메모를 저장합니다. 효과음은 후순위입니다.

사용자 확정 범위는 현황·미리보기·작업 관리입니다. 게임 수치나 플레이 저장은 편집하지 않습니다. 제작 메모는 `local-state.json`에 따로 저장하며 GitHub에는 올리지 않습니다. 소스를 수정한 뒤에는 서버를 재시작해야 새 정의가 반영됩니다.

관리 상태의 ‘완료’는 메모이며 실제 플레이 품질 검수 결과를 자동으로 보증하지 않습니다. 오래된 아틀라스와 현재 모델 구현의 차이도 각 항목의 근거에서 확인하세요.
