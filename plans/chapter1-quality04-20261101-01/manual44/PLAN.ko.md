# 실제 조작 전체 흐름 확인

최종 성능3회가 끝난 뒤 같은44 배포 EXE를 메뉴부터 실행한다. 정상 물리 시간과 실제 CUA 키·클릭만 사용하며 파일럿·자동 선택·시뮬레이션 재실행·보상 지급·강제승리를 쓰지 않는다. 관찰자는 입력/상태/기존 캡처/종료 결과만 기록한다. 저장은 비활성이고 현재 모든 사용자 진행의 집합과 SHA를 전후에 확인한다.

시작·이동·회피·회복약·성장 선택·장비 비교/장착·의식·봉인/구역 이동·보스·결과를 실제로 확인한다. 사망하면 실패로 기록하며 완주했다고 표시하지 않는다. 막힌 흐름과 화면 가독성을 다음 수정 근거로 삼는다. 기존 최초 저장 획득 검사를 반복하지 않고 음향 승인을 겸하지 않는다.
