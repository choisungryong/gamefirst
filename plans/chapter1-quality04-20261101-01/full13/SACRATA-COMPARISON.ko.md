# 후보13 · 고유 보스 개선과 남은 목표

목표는 SACRATA의 화려하고 읽기 쉬운 군중 전투에 디아블로식 장비 드롭·빌드·기술 성장을 결합한5–8분의 첫 장이다. 후보13은 보스 항목의 진전이며 최종 품질은 미달이다. 이전의 실제 원작 영상 관찰과 항목별 비교는 `../full11/SACRATA-COMPARISON.ko.md`와 도감 참고 분석 페이지에 보존했다. 이번에 새로 원작 전 영상을 연속 분석하거나 실청취했다고 하지 않는다.

후보12는 기능 검사와 전체 자동 입력이 통과해도 화면에서 보스가 과도하게 투명해져 채택하지 않았다. 원시 증거/EXE를 보존하고13에서 현재 자세의 몸통·머리·팔 겹침을 판정한다. 승리로 core tick이 멈추는 순간에도 사망 동작은 표현 시간을 사용한다. 전투/아이템/AI의 피해·확률·체력을 바꾸지 않았다.

다음 작업 순서는 냉기/번개 형태와 실제 빙결·파쇄 → 일반/정예 동작 → 공간 깊이 → 장비/보상 UX이며, 각 단계에서 현재 후보와 실제 GPU 화면을 비교한다.2·3장은 첫 장 품질 검수 뒤다. 기술 검사 성공만으로 SACRATA 수준 달성을 선언하지 않는다.
