# 성소 바닥27 · 미연결 source 시안

현재 제품26과 World22 연결은 유지한다. 새 chapter_world_quality27.gd / chapter_ground_quality27.gdshader는 미연결 연구 파일이다. EXE27은 만들지 않았다. 기존 바닥10의 텍스처·재질·단일 평면을 재사용하고 성소의 동심원에만 돌 이음새와 셰이더 음영을 추가했다. 충돌·좌표·게임 규칙을 바꾸지 않았다.

compare01/02/03은 서로 다른 외부 stage로 원본 소스·manifest·로그·6PNG씩 보존했다. 각 import/check/GPU exit0/stderr0 및 고정 core 전체 상태 불변, 기존 full26 freeze 불변을 확인했다. 실행 세션60974/11514/62579 모두 종료. 같은 검사를 재실행하지 않았다.

- compare01: World22 전/27 후 성소2장을 직접 검수. 이음새가 너무 검고 링 너비 안에서 분할 수가 바뀌어 원 가장자리가 불규칙하게 끊겼다. 기술 통과지만 시각 미채택.
- compare02: 분할 수를 링 중심 반지름으로 고정하고 돌 질감을 섞었다. 후 성소1장을 직접 검수했으나 차이가 거의 사라져 미채택.
- compare03: 돌 질감과 따뜻한 상감 색의 중간 대비로 조정, 중심의 작은 원 제거. 후 성소1장 직접 검수. 첫 시안보다 끊김과 대비가 줄었고 돌 블록 구분은 보이나 공간 깊이의 충분한 개선으로 승인하지 않는다. 현재 root 연구 파일은 이 버전.

18개 PNG가 모두 저장되었지만 직접 본 것은 위4장이다. source 비교는 고정 메뉴 core의 world-only 화면이며 배우·밀집전투·사용자입력·성능·실제 패키지 검수 근거가 아니다. 배우가 있는 동일 정상 획득 checkpoint에서 보스·탄막 가독성과 바닥 음영을 확인한 뒤 채택 여부를 판단해야 한다. 바닥 장식만으로 공간 깊이 문제가 끝났다고 간주하지 않는다.
