# 잿빛 회랑 · 1장 C2 후보04

대표 전투·성장·장비 비교 후보이며 5–8분짜리 1장 전체 또는 SACRATA 목표 품질의 최종 승인이 아닙니다.

AshenCloister-Chapter1.exe를 실행하고 시작 기술을 고르세요. WASD 또는 바닥 좌클릭으로 이동하고, Space로 회피합니다. 자동 시전하며 경험치 성장 화면에서 하나를 고릅니다. I 장비, Esc 정지/복원, M 음소거, R 패배/승리 후 재도전입니다. 화면 흔들림은 메뉴 버튼에서 조절합니다.

장비·성장은 현재 런에서만 유지합니다. 후보04는 기존 equipment-v1/progress-v1 저장을 읽거나 변경하거나 변환하지 않습니다. 정식 성능 원시는 별도 QA probe가 실제 실행된 경우에만 근거가 됩니다.
