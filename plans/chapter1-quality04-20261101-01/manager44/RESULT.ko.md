# 제작실44 개선

후보44의 실제183개 런타임·배포/보존 관문을 기준으로 선택한다. 번개 항목은 기존 경로 계산의14/36 근거와 현재44 재질 연결을 함께 보여준다. 세 스킬 각각 검증 장면2개를 제공하고 화염/빙결/파쇄/스턴 요소에도 연결했다.

검증 이미지는 별도 previews 필드다. 제품 에셋·파일 수나3D 모델로 섞지 않는다. 실제 고정 입력 장면과 분리 조건 빙결 장면을 설명하며 정지 이미지라고 표시한다. 기록이 없는 환경에서는 이미지 항목을 생략한다.

서버는 등록된 품질 검증 폴더의PNG만 추가 허용한다. 원본 사용자 파일/설정/경로 이탈을 허용하지 않는다. 임시 디렉터리의 allowlist·경로 이탈 검사 포함backend10개 및JS문법 검사 통과. 실제 제작실에서44 현황과 삼갈래/스턴 미리보기2개가 로드되는 것을 확인했다. 사용자 메모 파일은 별도 유지하며 로컬revision8의V02/V04검토 상태를 게임 품질 전체 완료로 확대하지 않는다.
