# 도감 v04 설계

기존 v03의 회랑 제작 도감 언어를 이어가고 원본 페이지는 보존한다. 새 허브의 핵심은 실제1장 화면과 세 마당의 동선이다. 큰 실전 화면 한 장을 표지에 사용하고, 장 구성/드롭/보관함/동작 연구/검증을 별도 페이지로 연결한다. 기술 통과 숫자를 과시하는 카드 표지는 쓰지 않는다.

색은 기존 회랑의 청회색 #1c272e, 깊은 돌 #121b21, 안개 #c2ced2, 잿빛 금 #c6ac75, 경고 갈색 #714b35다. 제목은 Batang/Georgia, 본문은 Malgun Gothic/sans-serif. 제목·설명·표·실제 화면 순서로 왼쪽 정렬한다. 장비는 슬롯별 묶음과 비교 가능한 효과 표, 동작은 채택/거절 사유를 이미지 옆에 둔다. 배경 움직임은 없다.

구조 초안: [제목·목표][실전 큰 화면][장 구성/장비/보관함/동작/검증 링크] → 각 상세 페이지의 실제 이미지·설명·증거. 단순 검증 대시보드처럼 보일 우려를 검토하여 상태 수치 카드와 장식 배지를 제거했다. 표지 이미지는 모형이 아닌 이번 후보의 실제 캡처만 사용한다. 기존 v03/39브리프는 역사 링크로 유지한다. 좁은 화면에서는 한 열로 바꾸고 키보드 포커스와 인쇄를 유지한다.
