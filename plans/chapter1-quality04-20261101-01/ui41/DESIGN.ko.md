# 초상 메뉴41 독립 소스

2026-11-11. 현재 후보40 통합과 분리해 다음 단계의 메뉴 소스만 준비했다. **엔진·GPU·제품 조립본에는 적용하지 않았다.**

## 화면 방향

기존 금기 서약의 회랑 방향을 유지한다. 왼쪽에는 360×540 논리 크기의 성인 마녀 초상, 오른쪽에는 제1장 제목·기존 목표 설명·실제 시작 기술3개·화면 흔들림/음소거·보관함·프로필 안내를 둔다. 초상 하나가 중심이며 나머지는 암색 석재와 절제된 황동으로 정리한다. 새 줄거리·능력·선택 요구를 추가하지 않는다.

초상은 새 AI 생성2D 원화다. 현재 남성 mage3D 모델을 바꾸거나 그 외형과 일치시킨 결과가 아니다. 3D·리그·움직임·텍스처 완료로 표시하지 않는다. 생성 기록과 원본은 `chapter1/art/portrait41/ATTRIBUTION.ko.md`, `PROMPT.txt`, `ASSET.json`에 있다.

## 구현과 기존 계약

`chapter1/view/ui41/chapter_hud_quality41.gd`는 UI40을 상속한다. `super._build_modal()` 이후, 실제 `menu`이고 보관함이 열리지 않은 경우에만 새 구성을 적용한다. 기존 메뉴의 세 시작 버튼 자체를 옮기므로 원래 skill-id를 캡처한 start 신호가 유지된다. 보관함 버튼·실제 profile_note·화면 흔들림 체크도 기존 노드와 콜백을 보존한다. 음소거 버튼은 기존 `mute_toggle` 신호를 사용하며 실제 상태를 허위로 표시하지 않는다. 마지막에는 기존 `_focus_modal38`로 Tab 순환과 첫 버튼 포커스를 재연결한다.

기존38·40 소스, 게임 코어·데이터·루트 조립본·스테이지·프로필을 수정하지 않았다. 전투·성장·장비·결과 UI는 UI40 상속 그대로다. 메뉴 구조가 예상과 다르면 기존 메뉴를 그대로 남긴다.

## 비율과 API 근거

원본1024×1536의2:3 비율과 같은360×540 `TextureRect`를 사용한다. `EXPAND_IGNORE_SIZE`와 `STRETCH_KEEP_ASPECT_CENTERED`로 원본 크기를 최소 크기로 강제하지 않고 전체 이미지를 비율 유지해 표시한다. 이미지 편집·왜곡·과도 크롭 없이 코드 네이티브 UI와 결합한다.

공식 Godot4.5 문서: https://docs.godotengine.org/en/4.5/classes/class_texturerect.html

## 후속 확인

아직 미채택·미실행 소스다. 별도 저장 비활성 스테이지에서720p/1080p 실제 메뉴와 그림 비율·넘침·한국어 줄바꿈·최초 포커스·Tab 순환·세 기술의 정확한 start 신호·보관함·음소거 신호를 확인한 다음 채택을 판단한다. 현재 후보40에는 자동 포함하지 않는다.
