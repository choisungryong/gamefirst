# 후보17 실제 네이티브 장비 입력

실제 EXE에서 정상pilot90131의코어를첫승리까지재구성해획득34개장비를열었다. 지급장비없고profile-off다. 이준비구간을수동전체플레이로세지않는다.

Windows컴퓨터사용으로확인한순서:

1. 겨울의심장고유설명/부적문양이보이는장비창확인.
2. 목록안에서마우스휠650입력으로내림.
3. 내려간위치의희귀반지'파쇄의수확의봉인의반지'클릭. 목록의보이는항목과스크롤손잡이위치유지, 반지문양/현재반지비교로갱신됨.
4. 장착버튼클릭. 현재장비/선택장비가같은이름·수치가되고목록◆장착표시갱신. 최대생명력176→188, 현재생명력147유지. 목록위치유지.
5. I키로닫음. 겨울의심장고유보상이있는승리창으로즉시정상복귀.
6. AltF4종료. 원시execution exit0/stderr0, 최종ring UID15/modevictory/scroll345/selected15. 휠입력650은OS이벤트량이고실제scroll345이며자동fixture의scroll650과구분한다.

이실행은저장비활성이라사용자보관함/저장을변경하지않는다. 창화면은컴퓨터사용도구로직접관찰했다. 네이티브저장UI/재시작지속성/전체수동/실청취/성능승인아니다.
