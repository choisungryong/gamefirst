## Blockers before real runs

1. Aggregate trusts saved independent-audit.json. It never rechecks current CSV, metadata, images, launch source hashes, execution or preservation evidence. A changed CSV after audit still allows a green aggregate. Extract a pure audit computation (separate from immutable audit writing); aggregate must freshly audit all three run folders, compare stored evidence hashes, and use fresh results. Resolve/canonicalize run directories, reject traversal/alias reuse, and require three distinct runtime directories/raw source identities, plus the same EXE, observer scripts, root/stage payload and exact user pins.

2. Raw validity is underbounded. Audit only requires the last elapsed >=70s and measured sum >=59s; it does not require the final row to be the FIRST crossing of 70s, strictly increasing noninitial elapsed across all phases, bounded warmup-boundary loss, first measured start close to 10s, or consistent first/last interval summary fields. Very large gaps or appended rows can pass eligibility. Retain genuine long intervals, but reject incomplete representative windows explicitly rather than silently approving them. Define a documented allowed boundary tolerance and useful minimum measured sample count; check first crossing, phase transition count, all positive noninitial intervals, sample start/end and exact telescoping sums. Recompute worst_ms and target flags, not just percentiles. Current nearest-rank p50/p95/p99 reconstruction is otherwise correct.

3. Runner is not exception-safe. check-only has no timeout/owned PID record. Main timeout terminate->wait(30) can raise again; preservation/copy/hash failures also abort before independent-audit evidence. Use owned Popen handles with bounded terminate then kill fallback, try/finally around every launched helper, record exception/timeout/actual final exit, and collect whatever artifacts exist plus preservation-after even on failures. Do not blanket-kill processes. Missing preservation files must produce a durable invalid result. Failures must not erase raw or promote success.

4. Exact 12 pins are not authenticated as the latest postfork set: len(user_pins)==12 accepts any twelve existing matching paths. Require the designated latest postfork37 manifest/schema and expected canonical path set (23/29/36/37 profiles and journals as specified by adoption), verify supplied pin manifest identity against adoption/fork proof, and bind it to each run. Current root/stage file hashes, EXE/build sha and before/after comparisons are useful, but include/hash build.json and closure.json themselves and bind stage identity, build hash and freeze/staging manifests to the expected37 package. Do not require old .godot cache bytes: caches were archived to D and are regenerable.

5. Observer error exits lack unified cleanup. Boot may call quit after view creation, preflight failure or configure rejection without stopping view processing, finishing/restoring probe, resetting audio, freeing view and releasing RefCounted/resource handles. Normal cleanup is improved from29 (file.close/null, queue_free+wait, probe=null), but route all exits through one cleanup path. Check mkdir/save_png/FileAccess.open return values; release boot texture/image handles explicitly before announcing READY. Probe configure can change OS.delta_smoothing then return false on metadata write before enabled=true, leaving no finish restoration path. Restore on every configure failure. Probe finish should propagate JSON/CSV write failures rather than silently setting done with a partial successful-looking summary.

6. Independent audit is not fully independent of configuration claims. It relies on summary.eligible_representative_run for movie/capture/fixed-fps/render-loop exclusions; recompute these from metadata and exact launch command, check profile-off, absence of autostart/ignorefocus/log/capture/movie/wallquit/fixedfps, ForwardPlus, scale1/MSAA2, uncapped/VSync off. Check source copies against launch observer_pins (and source pins stable before/after execution), probe-copy raw hashes against runtime originals, PNG signature/IHDR validity rather than only bytes16:24, before/after root window dimensions and script identities with durable errors rather than assert-only crashes.
