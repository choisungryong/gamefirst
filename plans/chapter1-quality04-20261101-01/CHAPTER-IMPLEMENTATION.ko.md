# 전체 1장 제작 계약 · 2026-11-01

목표는 사용자 지정 5–8분의 밀도 높은 한 장이다. 품질04의 대표 C2·90초 후보06은 보존한다. 다음 작업은 별도 ChapterOne 장면과 ChapterRun에 구현하고, 실제 정상 입력 한 판의 시간/공격 변화/피해/보상/저장과 화면을 검수한 뒤 실행 후보로 묶는다. 단순 5분 타이머·자동 승리·생명력 무한 QA로 완료하지 않는다.

## 플레이 연결

1. 잿빛 앞뜰: 즉시 전투, 첫 장비와 성장. 봉인 근처의 적 처치로 의식 목표를 채우고 첫 정예를 실제로 처치하면 동쪽 회랑이 열린다.
2. 무너진 성가대: 회랑을 직접 이동해 진입. 원거리/돌파군 비중 변화, 두 번째 봉인/다른 정예. 선택 의식 두 종류는 위치를 지키며 추가 적을 상대하는 위험과 보상을 교환한다.
3. 재의 성소: 세 번째 무리를 휩쓴 뒤 고유 보스 등장. 전조를 보고 피하는 부채탄/연속 장판과 생명력 절반의 패턴 변화. 실제 보스 처치가 승리 조건이다.

좌표는 (0,0), (48,0), (96,0) 중심의 작은 마당 세 곳과 두 짧은 회랑이다. 잠긴 다음 구역으로 이동을 막고 열린 구역 사이에는 로딩/텔레포트 대신 실제 이동을 쓴다. 매번 같은 마당의 색만 바꾼 것을 세 공간으로 세지 않는다. 구역별 바닥/폐허 배치/세로 구조/봉인과 문을 제공한다. 장거리 이동은 시간 채우기에 쓰지 않는다.

기본 군중/고정60Hz/실제 전조/군중 간격·공격 앵커 보존은 기존 코어를 재사용한다. 새로운 기능은 기본90초 동작을 유지하는 작은 가상 훅과 별도 하위 클래스로 분리한다. 최종 시간은 정상 플레이 측정으로 조정한다. 목표 수치 초안은 600/900/900 주변 처치, 정예2와 보스1이며 이것 자체가 재미나 시간 통과가 아니다.

## 성장·드롭·회복

기존 세 자동 기술의 랭크/패시브/진화를 유지하고 12단계 XP 곡선을 한 장의 예산으로 늘린다. 초기 유효 선택→주력 진화→보조/장비 효과의 세 번 이상 변화가 정상 플레이에 나타나야 한다. 세 진화를 매 판 전부 완성할 필요는 없다.

12 base(4슬롯×3)/12 affix, 품질별 옵션 수·자격·배타 그룹·값 범위, 빌드 전환 unique3을 독자 데이터로 구현한다. 피해 숫자만 바꾸지 않고 투사체/관통/연쇄/파쇄/화염 처치 폭발의 범위와 상한을 명세한다. unique가 통과 필수는 아니다. 자동 장착은 실제 사용자 선택에 쓰지 않는다. XP와 장비 회수/비교·장착은 분리한다.

긴 판에는 시작 회복약3개/최대5개, Q로 최대생명력35% 회복(소비·재사용 시간), 한정 회복약 드롭을 둔다. 정예 이후 회복 기회는 명시적 보상이며 무한 생명력/진단 자원 지급과 다르다. 회복 없는 장기 피해 누적으로 무조건 패배하는 설계는 피한다.

## 저장 경계와 인수

새 전용 프로필만 사용한다. 기존 D2R Combat Baseline equipment-v1/progress-v1 파일을 읽거나 변환하지 않는다. 장비/보상·최고 기록은 판 사이에 보존, XP/런 선택은 매 판 초기화. 저장 스키마/상한/손상 거부/임시 파일 교체·이전 사본을 검사한다. 유저에게 저장 성공/실패를 표시한다.

필수 검증은 잠긴 문/열린 회랑 이동, 각 봉인·정예 실제 처치, 사망/중단의 승리 방지, 보스 전조와 실제 판정 일치, 보상1회성·재시도 격리, 장비 생성 자격/상한/배타/효과, 저장 복원·오류 보존, 세 주력의 정상 입력 실제 한 판, 실제 GPU 플레이와 전후 영상이다. 합성 검사는 실제 손맛·음향 실청취를 대체하지 않는다.

현재 리깅 mage는 별도 연구 후보이다. 실제 Godot import/5클립/54bone은 확인했지만 어깨/옷감 변형과 사망 자세 수정 중이므로 기본 영웅을 아직 교체하지 않는다. 전체1장 기능 구현과 아트 검수를 함께 이어간다. 최종 품질·성능·실청취 관문은 열려 있다.
