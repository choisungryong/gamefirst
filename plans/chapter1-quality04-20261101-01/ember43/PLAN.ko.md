# 화염43 시각 개선

후보42 실행본·소스178개·사용자 진행을 보존하고 별도 스테이지에서 먼저 평가한다. 제품에는 아직 연결하지 않는다.

첫 범위는 두 재질의 교체다. 잿불탄은 기존 판정 위치와 Quad/방향/배치를 유지한 채 밝은 작은 중심, 가는 연속 심, 끝으로 가늘어지는 적색 꼬리를 구분한다. 실제 명중·처치·전파로 생성되는 기존 plume은 초기 크림색 고온부에서 짧은 불꽃과 낮은 잔화로 변한다. 새 전파나 가짜 명중을 만들지 않는다. 기존 파티클 수·풀·충돌·피해·RNG·수명·사운드를 바꾸지 않는다.

FX43은39를 상속하고 setup에서만 shader3개를 교체한다. 냉기 전용39 재질/배치는 그대로다. 공용 투사체 shader의 냉기·적 투사체 분기는14 원문과 동일하게 남긴다. 기존33 plume의 축소와 높이도 그대로다. 잔화의 시간은 INSTANCE_CUSTOM의 기존 age를 사용한다.

첫720p 비교에서 코어·표현 풀 해시가 모두 같고 실제 폭발184건을 확인했다. 흰 교차선이 불꽃을 가리는 화면 문제가 보여 두 번째 시도에서 접촉 재질도 함께 개선한다. 첫 시도 소스와 원시는 보존한다.

검증: 새 고유 스테이지 import/실제 Forward+ shader 컴파일 → 같은 seed/입력의 코어 및 표현 풀 상태 비교 → 720/1080p의 화염 시전/발사/명중/진화 전파/정지 장면 화면 비교. 새로운 명중 수치를 요구하는 테스트를 위해 코어를 수정하지 않는다. 화면을 확인한 뒤 채택 여부와 후속 번개 작업을 결정한다.
