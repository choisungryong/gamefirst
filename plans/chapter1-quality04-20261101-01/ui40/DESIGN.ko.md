# UI40 — 보관함·경로·결과

2026-11-11. 기존 UI38 제품과 고정 자료를 보존하고 신규 successor만 작성한다. 엔진/GPU 검증 전 소스 구현 상태다.

색과 글자는 UI38의 탄화 석재 `17191b`, 장비 바탕 `171e21`, 닳은 황동 `aa8d58`, 본문 상아 `e8d5a6`, 보조 회색 `c4bcaa`를 이어받는다. 명조 제목과 고딕 본문도 기존 테마를 사용한다. 장식보다 실제 장착·필터·진행 상태를 먼저 읽게 한다.

- 보관함: 상단 슬롯·등급·정렬, 왼쪽 목록과 장착 표식, 오른쪽 실제 효과와 다음 도전 장착/해체. 선택은 storage_id로 유지하고 선택 변경 시 목록 스크롤을 유지한다. 필터 변경은 목록 처음으로 돌아간다. 필터 결과가 비면 변경 방법을 설명한다.
- 구역 경로: 실제 세 구역 이름과 봉인 상태를 작은 띠에 표시한다. 현재 구역과 완료한 구역을 글자와 표식으로 구분한다. 다음 구역에 진입하기 전에는 실제 목적지까지 거리를 표시한다. 상세 지형·안개·적 위치를 흉내 낸 미니맵은 만들지 않는다.
- 결과: 시간·처치·레벨, 이번 도전의 보유 장비와 현재 장착, 실제 파수왕 보상, 실제 저장 안내, 보관함/재도전 순서로 묶는다. 도전 장비 수에는 시작 장비가 포함됨을 밝힌다. 보유 수를 새 획득 수로 꾸미지 않는다.

코드: `chapter1/view/ui40/chapter_hud_quality40.gd` → UI38 상속. run.objective()/seals/ZONE_NAMES, profile_state, inventory/equipped/pending_rewards, profile_note만 읽는다. 장착·해체·저장·재도전은 기존 신호를 사용한다. 코어·저장 파일·제품38 조립은 바꾸지 않는다.

검증 순서: 별도 stage에166개 제품38 소스+UI40 파일+검사 helper만 복사, 고유 custom_user_dir와 profile-off 사용. headless parser 후720/1080 실제 월드 캡처. 보관함 슬롯/등급 필터·정렬·선택 ID·스크롤 복원, 현재/완료 봉인과 목표 거리, 승리/패배의 실제 수치·장착·저장 안내와 키보드 경로를 확인한다. 합성 보관함/종료 상태 fixture는 실제 플레이 획득/승리로 기록하지 않는다. GPU는 root GO 전 실행하지 않는다.
