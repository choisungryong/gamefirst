2026-11-11. 신규 HUD successor만 추가했다. 제품38 소스168개 고정 해시를 확인해 불일치0개였으며, 제품38 조립·코어·데이터·저장 파일은 바꾸지 않았다. UI40은 아직 제품에 채택하지 않았다.

## 구현

보관함 슬롯/등급 필터, 최근 획득/등급/이름 정렬, 실제 storage_id 선택, 장착 표식과 비활성 장착 버튼, 선택 변경 시 목록 스크롤 유지, 빈 필터 안내를 추가했다. 장착·해체는 기존 신호에 ID만 전달한다. 구역 경로는 실제 세 구역 이름·seals·objective의 현재 구역과 진입 전 목적지 거리를 표시한다. 결과 화면은 도전 시간/처치/레벨·보유 장비·장착4슬롯·실제 파수왕 보상·저장 안내와 다음 행동을 묶었다. 시작 장비를 새 획득으로 계산하지 않는다.

## 실제 확인

작은 별도 stage `C:/Project/game-research/build-staging/chapter1-ui40-preview-20261111-01`에서 제품38 런타임166개+신규 UI40 한 개만 복사했다. stage 조립만 UI40으로 연결하고 고유 namespace와 profile-off를 사용했다. 실제38 월드/Core37/FX36에서720p·1080p 화면을 만들었다. 보관함48개와 세 구역 진행/승리/패배는 명시적인 검사 fixture다. 사용자 프로필을 읽거나 쓰지 않으며 실제 획득·수동 승리로 기록하지 않는다.

최종 `probe03/RESULT.json`:47개 확인 모두 통과, 종료0. 포함 범위는 정렬/슬롯·등급 필터 결과/빈 결과, 선택ID와 스크롤 유지, 장착·해체 요청ID, Tab 포커스, 세 구역 현재 표식, 종료 화면의 실제 fixture 수치·장비·저장 안내, fixture 원본 불변,14개 캡처 저장이다. 필터는 상태/API 기반으로 검증했으며 팝업의 모든 키보드 선택 조합을 검사했다고 확대하지 않는다.

실제 캡처 검토로 자동 줄바꿈 라벨이 가로 컨테이너에서 세로로 늘어나는 오류를 발견해 해당 경로/수량 라벨의 줄바꿈을 해제했다. 필터 패딩과 결과 창의 빈 공간을 줄였다. 마지막에는 경로 받침 폭을500으로 줄여 장비 발견 카드와 겹치지 않게 했다. 이전 시도와 캡처는 probe01/probe02에 보존했다.

원시: import01.log/parse01.log/probe03.log, `probe03/`의 stash/stash-empty/route-0/route-1/route-2/victory/defeat 각720/1080 캡처. Forward+ RTX2070 SUPER 렌더, SCRIPT/ERROR 없음. 검사 후 소유 Godot 프로세스 없음과 GPU 반납을 확인했다. 전체 성능·제품 통합·저장·수동 완주는 별도 단계다.
