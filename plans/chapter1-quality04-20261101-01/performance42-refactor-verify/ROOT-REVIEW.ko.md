# 최종 선택안 root 검토

2026-11-13. 추가 독립 작업자는 사용량 제한으로 실행되지 않아 root가 후속 검토와 엔진 검증을 직접 수행했다. 기존 REVIEW.ko.md의 최초 walker-only 검토를 새 부모 훅·캐시까지 독립 승인한 결과로 확대하지 않는다.

제품 부모 변경은 세 애니메이션 명령열을 기본 훅으로 옮기고, 재질 setter를 기본 훅으로 옮긴 것이다. 기본 훅은 기존 play→seek(true)→advance(0), 기존 albedo_color 할당을 그대로 수행한다. Actor42만 현재 AnimationPlayer 상태로 중복 play를 피하고 seek(true) 직후 중복 advance를 생략하며, 동일색 setter를 피한다. 실제 GLB 트랙은 transform 계열이며 이벤트·오디오 재생 트랙에 일반화하지 않는다.

같은 sync의 주인공 투영 캐시는 부모 Cloister.sync의 주인공 위치 갱신 이후 채운다. sync 밖 호출·다른 카메라·비minion 경로는 기존 구현으로 위임한다. 매 sync 종료와 reset에서 활성·준비 상태를 해제한다. 저장되는 값은 bool/int/Vector2/float이며 Node 참조를 보관하지 않는다. 배우별 overlap 결과 캐시는 실측 이득이 없어서 제품에 넣지 않았다.

별도 스테이지에서 직접8400, 전체15795, 확장8653 비교와 캐시 실제사용/해제 검증을 통과했다. 재질 후보에서도 전체·확장·캐시 비교를 다시 통과했다. 비교는 배우 transform, 전체 메타데이터, 자식 transform/visibility, skeleton pose, material/fade, AnimationPlayer 상태를 포함하며 허용 오차로 차이를 숨기지 않았다.

제품 채택 전 조립·부모2개를 백업했고 변경허용 경로를 명시했다. 후보42 루트178개·스테이지178개를 동결했으며 이전37/38/40/41 및 원41 실패시도도 보존했다. 저장은 현재41의 main+revision4개를 최초42 namespace로 바이트 그대로 복사하고 기존 사용자 진행을 수정하지 않았다.

실제 배포 통합27개 확인, 같은 EXE3회 유효 성능 관문 통과(p95 14.177/14.345/14.172ms). 전체 장 수동 완주·최악부하·모든프레임60FPS·음향 승인으로 확대하지 않는다. 현재 검토 범위에서 남은 동작 결함은 확인되지 않았으며, 후속 시각 개선은 별도 후보로 진행한다.
