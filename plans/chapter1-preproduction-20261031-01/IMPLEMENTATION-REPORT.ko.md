## 첫 구현의 검증 범위

Godot4.5.1 headless에서 `chapter1/tests/test_growth.gd` 정상 실행: actual exit0,188 checks, failures[]. 의도적 실패 옵션은actual exit1,189 checks, intentional harness failure를 확인했다. 정상과 실패를 구분해 검사 장치가 실패를 놓치지 않는지 확인했다. 검사는 root가 작성·실행했으며 독립 검증 담당자의 결과로 표시하지 않는다.

주요 확인:3계열의 주력 랭크→선행 패시브→진화 도달, 효과 정의의 투사체/범위/빙결·파쇄/연쇄 변화, seed 재현, 선택 재열기의 RNG 불변, 같은 선택 중복 commit 방지, 새 런에서 이전 token 무효, 잘못된 자격/범위/비정수 거부, detached 사본, XP/선택 큐 상한.

이것은 성장 코어의 검사다. 실제 자동 시전 스케줄러·타격·적·XP 오브·모달·장비·저장·VFX·음향은 아직 새 코어에 연결하지 않았다. 효과 정의가 변하는 것과 실제 화면/판정이 달라지는 것은 다음 통합에서 별도로 확인한다. 90초 제품/최종 아트/1장 완성 판정은 아니다.

## 페이지 사용

`book/dist/index.html`이 시작 파일이다. 표준 브라우저에서 직접 열 수 있도록 외부 라이브러리/폰트/서버 의존성을 두지 않았다. 인앱 브라우저의 file:// 프로토콜 차단 때문에 실제 파일 주소 열기는 도구로 검증하지 못했고, HTTP미리보기로 검수했다. 서버 시작 명령과 메모 이동 방법은 `book/README.ko.md`에 있다. 실제 인쇄/PDF 출력은 미실행이다.
