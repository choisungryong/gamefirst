# 제작 도감의 구성과 시각 설계

2026-10-31. 용도는 개발 중 계속 갱신하는 로컬 설계·에셋북이다. 판매 페이지나 공개 홍보 사이트가 아니다. 별도 dist에 정적 HTML/CSS/JS로 만들고 게임 export에 포함하지 않는다.

## 정보 구조

목표와 격차 / SACRATA 분석 / 스킬·성장 / 장비·파밍 / 적·보스 / 캐릭터·동작 / 환경·맵 / VFX·타격 / 음향 / UI / 에셋 원장 / 개발 순서 / 검수 / 출처의 개별 페이지. 에셋마다 고유 ID와 상세 주소를 준다. 검색·분류·필터·관련 항목 이동·원문 타임코드·원본 캡처 보기를 제공한다. 검토 메모는 이 브라우저에만 저장하며 JSON 내보내기/가져오기로 이동할 수 있게 한다. 인쇄 화면은 PDF 저장에 적합하도록 정리한다.

## 시각 방향

- 바탕 #18212a(차분한 청회색), 지면 #25313b, 본문 #e1e7e7, 보조 #a6b5bd, 제본/선택 #c4ac7b. 화염 #dd8c61·냉기 #82c9d7·번개 #b8a9df는 기술 계열 구분에만 사용한다.
- 본문 Malgun Gothic/맑은 고딕 계열, 제목 Batang/바탕 계열. OS 글꼴 이름을 사용하며 글꼴 파일을 배포하지 않는다. 본문16px·넉넉한 행간, 제목30–42px. 긴 한국어 문장은 좌측 정렬한다.
- 좌측 목차 + 중앙의 넓은 증거 이미지/설계 본문 + 필요할 때의 우측 제작 메타데이터. 모든 내용을 같은 카드로 잘게 나누지 않는다. 표는 실제 비교·사양·원장에 사용한다.
- 첫 화면은 참고 장면과 보존 시제품을 나란히 보여 주고 실제 문제와 제작 목표를 적는다. 큰 숫자·허구의 진행률을 홍보 문구로 쓰지 않는다.

```
목차 │ 제목 / 상태 / 인쇄
     │ 참고 장면          현재 시제품
     │ 차이와 채택 규칙    출처·판정
     │ 관련 제작 항목 목록
```

## 브리프 대조와 수정

초기 구상의 어두운 게임 포털은 에셋 목록을 화려하게 보일 수 있지만 근거와 미완료 상태를 숨길 우려가 있다. 그래서 배경 장식·입장 애니메이션·마케팅 문구를 빼고, 캡처/사양/출처가 중심인 제작 도감으로 수정했다. 다크 판타지 분위기는 제본 색과 제목, 실제 관찰 이미지에 집중한다. 원작/참고 이미지와 우리 제작 자산의 상태를 다른 필드로 유지한다.

## 작동·검증 기준

인터넷 없이 HTML과 로컬 이미지를 열 수 있어야 한다. 원문 영상/Steam 링크는 인터넷 필요라고 표시한다. 검색0건·메모 저장 실패·잘못된 가져오기·존재하지 않는 ID의 안내를 제공한다. 모바일 목차·키보드 포커스·대비·인쇄를 확인한다. 참고 캡처를 최종 보유 에셋으로 표시하지 않는다. 에셋이 미확보라면 실제 수급 상태를 그대로 보여 준다.
