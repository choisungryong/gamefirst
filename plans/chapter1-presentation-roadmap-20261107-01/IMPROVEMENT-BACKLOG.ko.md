# 체감 품질 개선 백로그

2026-11-07. 사용자 후보37 직접 플레이 뒤 요청한 실행 목록. 핵심 개선34개 + 후속 추가 후보6개. 이 목록은 기능/품질이 이미 완성됐다는 뜻이 아니다.

## 참고 기준과 사실 구분

SACRATA에서는 화면을 채우는 기술 변화·성장 선택·희귀 발견·성인 캐릭터 매력의 연결을 참고한다. D2R에서는 읽기 쉬운 정보·아이템 판단·구분되는 소리와 조절 가능한 음향을 참고한다. 각 자산과 수치를 그대로 복제하지 않는다.

현재 코드·화면에서 확인한 구조적 부족과 앞으로 직접 플레이/청취해 판단할 항목을 구분한다. 기본 주문음·명중음·드롭 기둥·장비 비교·성장 선택은 이미 존재한다. 아래는 그것을 제품 수준으로 개선하는 작업이다. 음원 파일과 로그를 읽었다고 실제 소리를 들었다고 하지 않는다.

공식 근거: [D2R 가독성과 음향 채널 안내](https://news.blizzard.com/en-us/article/23700733/how-were-making-diablo-ii-resurrectedtm-more-accessible-to-everyone), [D2R 스킬 표시·이동·UI 소리 개선](https://news.blizzard.com/en-gb/article/23746020/diablo-ii-resurrected-patch-2-3-highlights-coming-soon), [SACRATA 소개](https://store.steampowered.com/app/3201450/SACRATA/?l=english). 자세한 현재 소스 근거는 EVIDENCE.ko.md와 각 별도 계획을 따른다.

## 작업 방식

한 번에 활성 구현은1개다. 항목별 ‘현재→바뀐 결과→직접 플레이/청취’로 마친다. 단순 미술 수정에 전체 회귀를 반복하지 않고, 입력/저장/판정을 건드릴 때 해당 검사만 한다. 중간 결과를 바로 플레이할 수 있게 제공한다.

상태: 전 항목 대기. 사용자 플레이/피드백을 수집한 뒤 우선순위는 바꿀 수 있지만, 끝나지 않은 항목을 완료로 옮기지 않는다.

## 제안하는 첫 실행 순서

1. S01: 냉기 한기술의 발사/명중/파쇄 소리부터 짧게비교한다.
2. U01+U02: 같은시각체계로 핵심HUD부터 교체한다. 두ID는하나의작은HUD작업으로 묶는다.
3. U03: 성장선택을 보기좋고빨리판단할수있게 만든다.
4. U04: 현재/후보장비의실제차이를 명확히한다.
5. V01+V03: 같은냉기의시전·명중·파쇄를 화면과소리로 맞춘다.
6. C01+C02: 성인마녀아트시안과 성장/서약초상을 대표장면에넣는다.3D모델작업과구분한다.
7. S04+L01+L02: 좋은아이템을발견하는순간을다듬는다.
8. V06+L04: 보스전조·처치·보상까지한판의마지막을완성한다.

나머지는 위작업에서 확인된 불편과 사용자피드백으로 이어간다. 각항목완료시 짧은전후장면과플레이가능빌드를 제공한다. 이문서작성만으로어떤구현도완료처리하지 않는다.
