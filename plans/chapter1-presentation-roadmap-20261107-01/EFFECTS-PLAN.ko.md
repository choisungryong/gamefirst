# 효과·타격감·음향 개선 계획

## 목표

형태와 타이밍으로 시전→비행→명중→반동→처치를 구분한다. 화려함이 플레이어와 적의 전조를 덮지 않게 한다. SACRATA의 공간을 채우는 효과, 성장에 따른 공격 형태 변화, 희귀 발견과 보스 종료의 무게를 참고한다. 관찰하지 않은 개별 효과를 이미 분석했다고 주장하지 않는다.

## F1 — 냉기 대표60~90초 장면

구현: 기존 냉기1기술을 선택해 시전 손/지팡이의 짧은 빛, 날아가는 날카로운 코어, 실제 명중 지점의 파편, 빙결과 파쇄의 서로 다른 모양을 정리한다. 새 HUD와 함께 정상 밀집 장면에서 평가한다. 현존 효과를 단순히 더 많이 쌓는 방식으로 해결하지 않는다.

복사할 근거: chapter_view.gd:239–254의 event 소비/음향 연결, chapter_elements_quality36.gd:13의 실제 stun 만료 추적, quality14의 ice_targets/ice_shards 풀. 현재 particles960/strokes96/impacts48/ice_shards128 등의 상한은 초기 제작 경계다. 이 숫자가 성능 보장은 아니다.

확인: 발사·명중·빙결·처치가 움직임에서 구분됨, 위험 전조와 플레이어 위치가 계속 읽힘, 모달/정지 후 수명이 이상하게 진행되지 않음. 적중·처치의 실제 이벤트만 표현한다.

가드: 타격감을 위해 전역 시간이나 피해 틱을 임의 변경하지 않는다. 표현 노드가 피해를 주지 않는다. 효과를 숨겨 새 수치 결과를 맞추지 않는다.

## F2 — 세 속성·드롭·보스의 대비

구현: 화염은 뜨거운 중심과 짧은 잔화/처치 전파, 냉기는 선명한 파편과 맑은 파쇄, 번개는 밝은 중심선과 짧은 갈래/잔광으로 구분한다. 스턴의 금색 표시와 빙결의 냉색을 섞지 않는다. 고유 드롭·정예·보스 전조와 종료는 일반 적중보다 높은 중요도로 연출한다.

복사할 근거: quality36.gd:32의 실제 arc segments/from/to 메타데이터, quality33b.gd:8의 기존 희귀도별 beam/halo, quality26.gd:18의 아이템 라벨, chapter_one_view.gd의 gate/boss/ritual 이벤트. 이미 있는 드롭 기둥을 없는 기능처럼 다시 만들지 않는다.

확인: 세 속성의 화면 형태가 다름, 다수 동시 명중에서도 전조가 먼저 읽힘, 실제 갈래 연결·스턴 종료·라벨 소유권·드롭 큐가 유지됨. 비교 장면은 같은 코어/카메라에서 확인한다.

가드: 임의로 연쇄 대상이나 스턴 시간을 늘리지 않는다. 화면 흔들기 low/off를 유지한다. 희귀도 정보는 실제 아이템에서 읽는다.

## F3 — 소리의 중요도와 음악 흐름

구현: 기존 발사/명중/처치 레이어를 다듬고 성장·진화·보스 경고·승리에 전용 짧은 소리 역할을 부여한다. 탐색→압박→보스→종료의 음악/앰비언스 강약을 설계한다. 우선 기존 AudioStreamPlayer 구조를 사용하고, 음악/SFX 분리 설정을 추가할 때만 AudioServer 버스 문서를 별도 확인한다.

복사할 근거: presentation/combat_audio.gd:5–9의13voice/19variant/cooldown/gain, :58의 중요한 소리2voice 예약, chapter_view.gd:246–254와 chapter_one_view.gd:75–81의 이벤트 매핑. 현재는 Kenney CC0 가공 음원과 앰비언스이며 ‘모두 합성 사인음’이라는 과거 설명은 현재 사실이 아니다.

확인: 직접 청취로 명중/처치/경고/보상이 구분되고 군중 소리가 폭주하지 않음, 음소거/정지/재시작 정상, 출처·가공 이력 보존. 파형·음량·로그만으로 청취를 통과시키지 않는다.

가드: 중요한 피격·드롭이 잡음에 묻히지 않게 기존 우선순위·상한부터 유지한다. 출처 미확인 음원을 제품에 넣지 않는다.
