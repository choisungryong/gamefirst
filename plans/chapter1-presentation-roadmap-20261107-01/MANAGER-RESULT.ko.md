# 제작실 구현 및 실제 화면 확인

2026-11-07. 사용자 확정 범위: 현황·미리보기·작업 관리. 게임 데이터 직접 편집은 후속 단계다.

## 구현

`tools/game_manager`에 로컬 제작실을 추가했다. 소스에서 게임 정의·구현·에셋을 구분해 읽으며, 요소별 실제 속성·소스 줄·미리보기·관련 작업을 연결한다. 검색/분류/사용 구분/관리 상태 필터와 개선 작업40개를 제공한다. 효과음7개 작업은 후순위, UI38의4개 작업은 진행 중이다.

그림/SVG·음원 수동 재생과 로컬 GLB 모델/애니메이션 미리보기를 제공한다. 모델 뷰어4.1.0과 라이선스를 로컬에 보존했다. 존재하지 않는 Meshopt 디코더를 즉시 요청해 GLB가 실패하던 문제를 실제 브라우저에서 발견하고 수정했다. 좁은 화면의 고정 사이드바도 상단 분류와 단일 열로 바꿨다.

## 확인한 결과

- 실제 브라우저에서 장비12·기술3·몬스터4 등 의미 단위 분류를 확인했다. 등록 항목에는 구현과 에셋도 포함되므로 총수를 게임 종류 수로 표시하지 않는다.
- 주인공 GLB가 실제 렌더됐고 idle/run/cast/hit/death 목록, cast 선택·재생·일시정지를 확인했다.
- 서리창 개선 메모를 저장하고 새로고침 후 같은 메모가 남는 것을 확인했다. UI38 작업 메모도 저장했다.
- 목표40개, 효과음 후순위7개, UI38 진행4개의 실제 보드 표시를 확인했다.
- 백엔드4개 검사는 소스 카탈로그 의미·경로 허용·Host/Origin·메모 지속성/충돌/잘못된 입력을 확인했다.

화면 원시: `proof/manager-character.png`, `proof/manager-ui38-task.png`. 이 결과는 게임 전체 플레이·음향 청취·모든 모델 품질 승인을 뜻하지 않는다.

## 실행과 보존

바탕 화면 **잿빛 회랑 제작실** 또는 `tools/game_manager/open-manager.ps1`로 연다. 주소는 http://127.0.0.1:8781/ 이며 서버는 로컬에만 바인딩한다. 기존 v44 도감·작업대는 원위치에서 연결한다. 메모는 별도 `local-state.json`에 저장하고 GitHub에 포함하지 않는다. 플레이 프로필을 읽거나 수정하지 않는다.

후속 순서는 검증된 후보38 카탈로그 연결 → 냉기 시각 표현 → 다른 속성/캐릭터 단계다. 관리 메모의 완료와 제품 품질 검수 완료를 구분한다.
