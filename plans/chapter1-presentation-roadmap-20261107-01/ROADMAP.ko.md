# 제1장 표현 품질 개선 계획

2026-11-07. 사용자 직접 플레이를 먼저 제공하고, UI·전투 표현·성인 캐릭터 매력을 별도 제작 단위로 진행한다. 현재 안정 비교본은 후보37이며 그대로 보존한다.

## 지금 제공한 플레이

바탕화면의 ‘잿빛 회랑 - 제1장’ 바로가기는 후보37 실행본을 연다. 시작 화면을 열어 사용자에게 제어권을 넘겼다. 사용자가 플레이하는 동안 자동 입력·GPU 검사·프로세스 종료·저장 재작성은 하지 않는다. 현재 기준 저장은37 revision3/장비23/완료1/body1이다. 이후 사용자 플레이로 생기는 진행을 정상 데이터로 보존하며 이전13핀으로 되돌리지 않는다.

후보37은 패키징·저장 연속성·석재 개선을 확인한 시제품이다. 최종 성능3회, 수동 완주, 실제 청취는 완료되지 않았다. 사용자 체험을 이 관문 뒤로 계속 미루지 않는다.

## Phase 0 — 근거와 작업 경계: 완료

[EVIDENCE.ko.md](EVIDENCE.ko.md)에 현재 소스, 실제 사용 가능한 인터페이스, 공식 문서, SACRATA 관찰 범위를 정리했다. 과거 시제품의 한계를 현재37의 사실로 옮겨 적지 않는다. 자료 추가가 필요하면 해당 기능을 만들기 직전에 확인한다.

## 실행 순서

1. 현재 플레이와 별개로 UI 시안부터 만든다. 먼저 핵심 HUD, 성장 카드, 장비 비교의 세 화면을 같은 스타일로 제시한다. 사용자 피드백은 해당 시안과 현재 게임 경험에 반영한다.
2. 기존1장 공간에서60~90초 대표 장면을 만든다. 새 HUD, 냉기1기술의 타격 표현, 성장 또는 고유 드롭, 성인 마녀 초상 연출을 함께 연결한다.
3. 대표 장면에서 글자·선택·위험 가독성·매력·소리를 확인하고 같은 제작 방식을 화염/번개·나머지 화면으로 확장한다.
4. 후속 보스는 별도 후보에서 서큐버스 모델·동작·전조를 제작한다. 초상만 추가한 상태를3D 보스 완성으로 표시하지 않는다.
5. 선택한 최종 후보를 한 번 고정한 뒤 동일 실행본 성능3회와 전체 플레이·저장·청취를 묶어 마무리한다. 중간 미술 시안마다 전체 관문을 반복하지 않는다.

## 진행을 빠르게 유지하는 규칙

- 시각 변경은 필요한 실제 화면과 연속 플레이로 판단한다. 단순 색·여백 수정에 구현을 그대로 따라가는 테스트를 만들지 않는다.
- 입력/선택/저장/판정 경계를 바꿀 때만 관련 기능 검사를 수행한다. 넓은 회귀는 통합 후보에서 한 번 한다.
- 새 범용 도구, 엔진 교체,2·3장 확장은 선행조건으로 삼지 않는다.
- 실제값을 읽는 UI와 표현 이벤트만 변경한다. 피해/RNG/보상 소유권/사용자 저장은 기존 코어가 권위를 가진다.
- 소스·라이선스·계획은 Git으로 보존한다. 캐시·EXE·대량 캡처·사용자 저장은 업로드하지 않는다. 추가 스테이지 복사를 최소화한다.

## 품질 판단

기능 존재와 미술 완성은 별도로 기록한다. 대표 장면의 정지 화면, 실제 움직임, 선택의 이해도, 직접 들은 소리, 사용자 체감이 모두 필요하다. SACRATA는 표현의 목표 기준이며 그 자산·캐릭터·화면 구도를 복제하지 않는다.
