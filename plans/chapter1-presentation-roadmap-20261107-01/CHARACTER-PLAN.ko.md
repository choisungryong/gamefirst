# 성인 캐릭터 매력·의식·서큐버스 계획

## 목표와 고유 방향

기존 ‘어두운 회랑과 금기 서약’ 소재를 성인 마녀/원소술사의 매력으로 연결한다. 섹시함은 성인 얼굴, 자신감 있는 자세, 어깨·허리의 의상 실루엣, 천·금속·피부 재질의 대비, 절제된 시선과 동작에서 만든다. 전투 중앙을 상시 가리는 큰 일러스트 대신 선택·발견·승리의 호흡을 활용한다.

SACRATA 공식 소개의 여신 캐릭터 매력 방향은 참고한다. 그 캐릭터나 획득 장면을 그대로 복제하는 계획은 아니다. 기존 보스와 주인공이 이미 이런 디자인으로 교체됐다고 기록하지 않는다.

## C1 — 성인 마녀 아트 시안과 선택 연출

구현: 오리지널 성인 캐릭터의 얼굴·의상·전신 실루엣·색·장신구를 하나의 아트 시트로 정한다. 먼저 성장/금기 서약 화면에 들어갈 성인 마녀 초상과 짧은 등장 연출을 만든다. 대표 시안은 한 방향을 충분히 완성해 판단하며, 수정 전 원본도 보존한다.

복사할 근거: ART-DIRECTION-ATTRACTION.ko.md의 성인 의식/서약 방향, 새 UI U3의 성장 token/card 흐름, 기존 초상/텍스처 표시 Control 패턴. 새 페이드는 공식 Node.create_tween()/tween_property() 예제를 읽고 사용한다. Tween.new()로 동작한다고 가정하지 않는다.

확인: 성인성·게임 고유 소재·작은 크기의 얼굴/실루엣 가독성, 카드 설명과 선택 버튼을 가리지 않음, 건너뛰기/모션 감소 시 선택 의미 동일. 초상만 만든 상태를3D 주인공 완성이라고 하지 않는다.

가드: 유사 캐릭터나 원작 화면 구도의 복제, 어린 외형, 노출만 늘려 문제를 해결하는 시안을 피한다. 캐릭터 매력과 전투 목적이 함께 읽혀야 한다.

## C2 — 인게임 성인 주인공 모델·움직임

구현: 채택한 콘셉트에 맞는 실제3D 모델·재질·리그를 제작/확보한다. idle/run/cast/hit/death와 이동 중 상체 시전의 계약을 맞춘다. 원화 제작과3D 자산 제작은 별도 산출물이다. 현재 사용 가능한 도구와 제작 경로를 확인한 뒤 모델 제작 범위를 확정한다.

복사할 근거: view/rigged_hero_actors.gd:109의 _update_pose, chapter1/art/rigged_mage/v01/ATTRIBUTION.ko.md의 원본/파생 구분. 기존 리그를 무조건 새 모델에 적용하지 않고 bone/skin/clip 이름과 샘플 좌표를 먼저 확인한다.

확인: 실제 카메라 거리에서 자세와 의상이 구분됨, 이동·시전·피격·사망 연결, 천/피부/금속의 과도한 광택과 관절 찌그러짐 없음, 장비/가림 효과 회귀 없음. 자산 출처와 수정 파일 보존.

가드: 기존 CC BY-SA 모델을 수정한 결과를 완전 독자 제작물로 표기하지 않는다. 모델 미확보를 숨기기 위해 초상만으로 이 단계를 완료하지 않는다.

## C3 — 성인 서큐버스 후속 보스

구현: 기존 보스를 보존한 새 후보에서 성인 서큐버스를 설계한다. 날개·꼬리·의상·자세, 유혹적인 시전과 이동을 만들되 공격 전조와 실제 판정의 타이밍을 유지한다. 패배는 무릎 꿇기·날개 접기·기대어 쓰러지는 동작에서 보상으로 연결한다. 보스의 매력 표현과 플레이어가 읽어야 할 위험을 함께 설계한다.

복사할 근거: ART-DIRECTION-ATTRACTION.ko.md의 보스 요청, chapter_actors_demon19.gd:51 이후 실제 windup/release 샘플링, chained_warden/v01의8clip 계약과 재질 분리 기록. 새 모델에 기존 skeleton 캐시를 적용하지 않는다.

확인: 실루엣/전조/두 공격/피격/단계 변화/패배/보상을 연속 플레이로 확인. 보스 근접·원거리·시야 가림에서 공격이 읽힘. 캐릭터 교체 전후 보상 소유권과 저장 정책은 동일.

가드: 미술 때문에 공격 판정을 모르게 바꾸지 않는다.2·3장이나 추가 캐릭터 대량 제작을 선행조건으로 삼지 않는다.

## 최종 확인

대표60~90초 장면에서 UI·초상·전투 효과와 함께 매력을 평가한 뒤 확장한다. 실제 인게임3D/움직임/소리와 원화의 완성도를 구분해서 기록한다. 성인 매력 시안이 준비되면 사용자가 직접 보고 플레이할 수 있는 빌드를 제공한다.
