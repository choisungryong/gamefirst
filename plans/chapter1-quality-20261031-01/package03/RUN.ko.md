# 잿빛 회랑 · C2 품질 개선 후보03

`AshenCloister-Chapter1.exe`를 실행하세요. 약90초의 대표 전투 구간이며 목표인5–8분짜리1장 전체는 아직 완성되지 않았습니다. SACRATA 수준의 최종 품질 승인도 열려 있습니다.

- WASD 또는 마우스 좌클릭: 이동
- Space: 회피 · 기술은 자동 시전
- 성장 화면에서 강화 선택
- I: 장비 확인·비교·장착
- Esc: 정지·재개 · M: 음소거 · R: 결과 화면에서 재도전
- 메뉴의 화면 흔들림 선택으로 카메라 흔들림 조절

70초에 등장하는 회랑 수호자를 실제로 처치하면 승리합니다. 시간만 지나서 승리하지 않습니다. 장비와 성장은 이번 플레이에서만 유지되며 저장 기능은 없습니다. 기존 실행본이나 기존 세이브를 읽거나 변경하지 않습니다.

새 돌길·흙바닥·폐허·식생, 네 방향 시전, 속성별 효과와 CC0 음향을 적용한 독립 제작2.5D 후보입니다. 이동은 기존4방향×4키프레임이며, 새8프레임 달리기를 구현했다는 뜻은 아닙니다. 보호되는 원작 코드·그래픽·음향을 복사하지 않았습니다. 음향 출처·허용 조건과 생성 아트 기록은 `credits` 폴더에 있습니다.
