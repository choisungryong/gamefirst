# 전투 표현 제작 방향

기존 회색·청록 화면에 얇은 흰 선만 늘어나는 문제를 고친다. 주인공의 세 원소가 장면의 가장 강한 빛이 되고, 적의 준비 동작과 전조는 위험 위치를 읽는 낮은 층으로 남는다.

- 숯빛 철 `#171512`, 청흑 `#22282c`, 낡은 황동 `#aa8550`, 뼈색 `#e5d8bb`, 잿불 `#ff6b1a`, 얼음 `#8edbea`.
- 실시간 정보는 맑은 고딕 15–17px, 선택·결과 제목은 바탕 계열 25–36px. 장식 문구보다 생명력·기술·장착 결과가 먼저 읽힌다.
- 하단: `[생명력·XP] [화염 / 냉기 / 번개] [회피]`. 기존90px 높이 패널은 줄여 전장을 확보한다.
- 화염은 붉은 껍질·주황 불꽃·짧은 백열 중심과 짙은 연기. 냉기는 각진 창과 파쇄편. 번개는 굵기가 다른 짧은 가지 번개.
- 전조는 실제 core의 유효 형상을 보수적으로 포함한다. 일반 적은 엷은 붉은 갈색, 정예는 선명한 가장자리와 준비 원으로 구분한다.
- 피해·사망·보상은 원래 core가 결정한다. VFX는 paid event/projectile 속성만 읽고 현재 장비/랭크에서 비행 중 공격을 다시 계산하지 않는다.

흔한 녹색 반투명 패널과 기능 전체를 감싼 동일한 카드 대신, 철·황동과 원소별 색을 실시간 정보에만 사용한다. 독립 제작 UI 기호는 기술 식별을 돕고, 큰 장식 아이콘이나 HUD 광원으로 전투를 가리지 않는다.
