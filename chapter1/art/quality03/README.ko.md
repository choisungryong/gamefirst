# Quality03 신규 아트 공급 · 2026-10-31

기존 아트/원장/실행 후보02를 수정하지 않고 새 `chapter1/art/quality03/`에 공급했다. 모든 이미지는 **built-in image_gen.imagegen**으로 생성했고 원본 PNG를 그대로 복사했다. CLI/API 대체 경로와 Python 이미지 편집은 사용하지 않았다. Python은 알파 연결 요소·사각형·발 기준점 메타데이터 분석에만 썼다.

## 제공하지 않은 달리기

`attempts/hero_run_attempt01.png`, `attempts/hero_run_attempt02.png`는 4방향×8포즈를 요청한 생성 원본 사본이다. 두 시도 모두 정지 시트 관찰에서 앞선 발이 거의 유지되고 망토/자세만 변하는 문제가 남아 **실제 좌우 다리 교환·접지·공중 단계가 있는 달리기로 채택하지 않았다**. 두 번째는 다리 단계만 고치는 표적 수정을 요청했으나 조건을 충족하지 못했다.

따라서 `hero_run_v01.json`을 만들지 않았고, 기존 4프레임 보행이 대체되었다고 주장하지 않는다. 엔진 담당자와 부모에게 이 제한을 전달했다. 32개 그림이 있다는 숫자를 애니메이션 품질로 바꾸어 보고하지 않았다.

## 메타데이터 계약

소품 JSON은 `props[{id,region:[x,y,w,h],feet:[localX,localY],height_m,category}]`다. 균일 셀 절단 대신 가변 사각형을 사용한다. 고사목은 명목상 행 경계를 넘어가지만 제공 사각형 안에 전체 주요 연결 요소가 있으며 이웃 요소는 없다.

시전 JSON은 기존 프레임 계약에 `frames_by_direction`과 `states.cast_south/east/north/west`를 제공한다. 각 방향 프레임의 PPM은 일정하다(남127.805/동119/북122.662/서120.927). 프레임2가 발사 포즈이며 각 방향은 준비→예비→발사→회복 순서다. PNG 픽셀을 재배치하거나 잘라 새 이미지로 만들지 않았다.

## 출처·검사·실패 보존

- 최종 원장: `ASSET-LEDGER-v04.json`. 채택 시험용 PNG5개와 거절한 달리기 PNG2개를 구분한다. 7개 사본 모두 생성 원본 SHA256과 일치한다.
- 모든 최종 프롬프트·참조 이미지·생성 원본 경로가 원장에 있다. 생성 결과를 CC0 또는 제3자 라이선스 모델로 표시하지 않았다.
- `PROP-INSPECTION.json`, `HERO-CAST-INSPECTION.json`, `FOLIAGE-INSPECTION.json`에 알파 검사를 남겼다.
- 첫 시전 메타데이터 스크립트는 상위 경로 선택 오류로 actual exit1이었다. 원문 `finalize_art_metadata.py`를 보존했다. `finalize_art_metadata_v02.py`는 읽기 경로를 수정하고 이미 복사된 PNG의 원본 해시 일치만 확인하여 actual exit0으로 마쳤다. `ART-METADATA-RECOVERY.json`에 기록했다. 게임 결함이나 이미지 픽셀 수정으로 보고하지 않는다.
- `build_art_metadata.py`, `finalize_art_metadata_v02.py`, `finalize_foliage.py`는 각각 실제 exit0으로 복사/메타데이터 검사를 마쳤다. 고정 출력이 존재하면 덮어쓰기를 거부하므로 역사 출력을 대상으로 다시 실행하지 않는다.

GPU/실기 입력은 이 아트 공급 담당자가 수행하지 않았다. 지면 이음새·소품 크기/접지·가림·시전 연속 동작·폴리지 밀도·성능의 최종 판정은 동일 카메라의 실제 실행을 확인하는 부모/통합 담당자의 몫이다. 보호되는 원작 자산 복사·업로드·유료 구매·커밋은 하지 않았다.
