# 금기 서약의 마녀 초상 v01

2026-11-11 제작. OpenAI 내장 `image_gen` 도구로 생성한 AI 이미지다. 외부 게임의 캐릭터 이미지나 실존 인물 사진을 입력하지 않았다. 최종 생성 프롬프트는 `PROMPT.txt`에 보존했다. CLI/API 폴백은 사용하지 않았다.

## 파일과 용도

- `oath_witch_portrait_v01.png`: 1024×1536 PNG, 어두운 배경을 포함한 세로 초상.
- 성인 마녀/원소술사의 성장·금기 서약·결과 UI 초상용 이미지다. 얼굴과 의상은 새 디자인이며 어두운 가죽·보라빛 직물·황동·작은 붉은 서약 인장을 사용한다.
- 이 파일은 2D 초상이다. 현재 플레이어의 3D 모델·리그·애니메이션을 교체하거나 완성한 산출물이 아니다. 제품 UI 연결도 별도 단계다.

## 시각 확인

생성된 실제 이미지를 직접 확인했다. 명백한 성인 얼굴, 완전히 입은 의상, 정면을 바라보는 3/4 자세, 어두운 단순 배경, 얼굴의 작은 크기 가독성을 위한 밝은 면을 확인했다. 텍스트·워터마크·로고·UI·추가 인물은 없다. 투명 배경 파일이 아니므로 사각 카드의 어두운 배경이나 얼굴 영역 크롭에 사용한다.

SACRATA·디아블로의 구체적 캐릭터를 복제한 자산으로 표시하지 않는다. 생성물에 임의의 CC0/CC BY 등 제3자 라이선스를 부여하지 않는다. 실제 게임 UI에서의 크롭·크기·한국어 배치 검증은 소비 화면을 만든 뒤 수행한다.

원본 생성 파일은 Codex의 `generated_images` 폴더에 그대로 남겼으며 선택한 이미지를 프로젝트에 복사했다. 기존 게임 소스·조립본·패키징 스테이지·프로필은 변경하지 않았다.
